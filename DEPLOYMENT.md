# Развёртывание Couple Space

## Основная среда: Vercel

Продакшен собирается нативным Next.js через `npm run build`. Файл `vercel.json`
намеренно указывает именно эту команду. Все изменения API, Realtime, изображений,
переменных окружения и маршрутизации сначала должны проходить проверку
`npm run verify:vercel`.

Переменные Supabase задаются отдельно для нужных окружений Vercel. Основной URL
берётся из `NEXT_PUBLIC_SUPABASE_URL`; при необходимости origin для rewrites можно
переопределить через `SUPABASE_ORIGIN`.

## Вторичная среда: Sites

Sites используется как тестовая, резервная и черновая среда. Её отдельная сборка
`npm run verify:sites` запускается только после успешной нативной сборки Next.js.
Совместимость с vinext не должна определять архитектуру или ограничивать основной
продакшен на Vercel.

## Порядок выпуска

1. `npm run verify:vercel`
2. `npm run verify:sites`
3. Push в `main` — основной выпуск через подключённый к Vercel Git-репозиторий.
4. Обновление Sites — вторичная публикация после успешного Vercel-пайплайна.
